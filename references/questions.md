# ふりかえりの問いカタログ

出典: https://hurikaeri.jp/questions/ (ふりかえり実践会)

## チェックイン・場の状態(ふりかえりの場を作る)

ふりかえりの冒頭で、参加者の状態・期待・場のルールをそろえる問いです。いきなり本題に入らず、まず場をひらくことで、そのあとの発言のしやすさが変わります。

- いまの気分・状態を一言で表すと何ですか
- 直近24時間にあった「良いこと」は何ですか
- 直近24時間にあった「新しいこと」は何ですか
- 今日のふりかえりに期待することは何ですか
- 今日のふりかえりで話したいことは何ですか
- いま気がかりなこと・不安なことは何ですか
- 今日のふりかえりに、どんな姿勢で参加していますか
- この場をどんな場にしたいですか
- この場でみんなで守りたい約束は何ですか
- いまのチームで、本音をどれくらい話せていますか

## 事実(出来事を思い出す)

主観と客観、定性と定量、成功と失敗の3つの観点で、起こったことを引き出します。主観を出し合って認識のズレを埋め、定量で変化を可視化しましょう。

- 何をしましたか／しようとしましたか
- 何が起こりましたか／起こらなかったですか
- 何を意識しましたか／忘れていましたか
- 想定通りだったものは何ですか／想定しなかった出来事は何ですか
- どんな変化を起こしましたか／起こせなかったですか
- どれほどの効果がありましたか
- 数値で確認できる変化はありましたか
- どれほどの時間がかかりましたか
- 自分から／チームから見えたものは何ですか
- 自分にしか見えていなかったものは何ですか
- 得られたもの／失われたものは何ですか
- 前はできていたのに、できなくなったことは何ですか
- 行動の背景・前提となっていた状況は何ですか
- メンバーとのコミュニケーション・協働はどうでしたか
- そこで何が起こりましたか

## 感情(出来事を思い出す)

プラスの感情は自己効力感に、マイナスの感情は理想とのギャップを知るチャンスにつながります。感情は事実とセットで出すのがコツです。

- 楽しいと感じたのは何ですか／いつですか。なぜそう感じましたか
- 嬉しいと感じたのは何ですか／いつですか。なぜそう感じましたか
- 悲しいと感じたのは何ですか／いつですか。なぜそう感じましたか
- 憤り・怒りを感じたのは何ですか／いつですか。なぜそう感じましたか
- ストレス・フラストレーションを感じたのは何ですか／いつですか
- つらいと感じたのは何ですか／いつですか。なぜそう感じましたか
- 危険・危機を感じたのは何ですか／いつですか。なぜそう感じましたか
- 以前と同じ／違う感情になったのは何ですか。なぜそう感じましたか
- （ふりかえりの対象期間に）点数をつけるとしたら何点ですか。なぜそう感じていますか
- 感情が最も揺れ動いたのは何ですか／いつですか
- （対象期間で）感情はどのように変化していましたか。傾向はありますか
- 気持ちや気分が高まったのはいつですか。それは何ですか
- 気持ちや気分が落ち込んだのはいつですか。それは何ですか
- 最も○○（楽しい／悲しいなど）と感じたのは何ですか／いつですか
- いまのチームの状態を、オノマトペ（擬音語・擬態語）で表すと？
- あなたを動かす「動機」は何ですか

## 時系列とイベント(出来事を思い出す)

時間軸やイベントをきっかけに思い出します。時系列順に思い出す必要はなく、思い出せるところから周辺へ広げていけばOKです。

- ○○月／○○週／○○日／○○曜日に起こったことは何ですか
- 朝／昼／夕／夜に起こったことは何ですか
- （ある出来事の）前に／後に起こったことは何ですか
- （ある出来事の）原因となった出来事は何ですか
- （ある出来事が）原因となって引き起こされた出来事は何ですか
- 定期的に行われるイベント／会議／打ち合わせで行ったことは何ですか
- 突発的に発生したイベント／会議／打ち合わせで行ったことは何ですか
- 普段とは違うイベントはありましたか。それはなぜ行いましたか
- 最近／少し前／昔に起こったことは何ですか

## よかったこと・続けたいこと(アイデアを出し合う)

うまくいったこと、続けたいこと、やり遂げたことを引き出す問いです。多くの手法がこの軸を持っています。課題ばかりに向かいがちなふりかえりの偏りを戻す役割もあります。

- 続けたいこと・次も繰り返したいことは何ですか
- よかったことは何ですか
- やり遂げたこと・完了したこと・勝ち取った成果は何ですか
- 役立ったもの・助けになったものは何ですか
- あなたやチームを前に進めてくれたものは何ですか
- あなたやチームの「強み」が発揮された場面はどこですか
- 継続してできたことは何ですか
- 気に入ったものは何ですか
- できたことは何ですか
- うまくいったことは何ですか

## 課題・もやもや(アイデアを出し合う)

問題・課題や、言葉にしづらい「もやもや」を引き出す問いです。大きな問題になる前の小さな違和感や、みんな気づいているのに触れられていないことを扱います。

- 問題・課題だと感じていることは何ですか
- 「問題」と言うほどではないけれど、もやもやしていることは何ですか
- 足りなかったものは何ですか
- チームの進みを遅らせているものは何ですか
- みんな薄々気づいているのに、話題にできていないことは何ですか
- 放っておくと、そのうち大きな問題になりそうなことは何ですか
- 言ってしまえば楽になる、吐き出してしまいたいことは何ですか
- その仕組み・活動は、どれくらい頑丈ですか
- 気になったこと／気がかりなことは何ですか。それはなぜですか
- できなかったことは何ですか
- うまくいかなかったことは何ですか

## 学びと気づき(アイデアを出し合う)

学びを引き出す問いは、ふりかえりの中でも一番難しいところ。問いの種類をいくつも持って、さまざまな角度から引き出しましょう。

- どんな学びや気づきがありましたか。それはなぜですか
- 興味があるもの／興味を惹かれたものは何ですか
- 良い方向／悪い方向に変わったところは何ですか
- とくに良いところ／悪いところは何ですか。なぜそう感じましたか
- どんな傾向が見えましたか。それはなぜですか
- どんな考えの違いがありましたか。なぜそう感じましたか
- 今までと同じこと／違うことは起こりましたか
- 今までとどう印象が変わりましたか。それはなぜですか
- 一番印象に残ったことは何ですか。それはなぜですか
- ここにいない人に何を伝えたいですか。それはなぜですか
- これだけは伝えたい／教えたいというものは何ですか
- 驚いたことは何ですか
- なぜそれが起こったのですか（「なぜ」を繰り返して深掘りする）
- 成功から何を学びましたか
- 失敗から何を学びましたか
- それは「ミス」「実験」「いつものプラクティス」のどれから生まれましたか
- その学びは、チームへのどんな貢献につながりますか

## 感謝・称賛(アイデアを出し合う)

感謝や称賛を伝え合う問いです。成果ではなく関係の質に働きかけます。チームの雰囲気が重いときや、節目のふりかえりに向いています。

- 感謝を伝えたい人・出来事は何ですか
- お互いの挑戦に、どんなエール・応援を送りますか
- 謝りたいこと・素直に伝えたいことはありますか
- 感謝の気持ちを感じたのは何ですか／いつですか。なぜそう感じましたか

## 過去・現在・未来・理想・ギャップ(出来事を思い出す)

時間軸別に事実や感情を引き出します。未来・理想とのギャップを話し合うと、アイデアやアクションにつながりやすくなります。

- 今起こっていることは何ですか
- すぐに／少し先に／未来に起こることは何ですか
- すぐに／少し先に／未来に起こしたいこと／成したいことは何ですか
- あなたの／チームの理想は何ですか
- 過去と現実との変化は何ですか。どうして変化が起こりましたか
- 現実と理想のギャップは何ですか。ギャップの理由は何ですか
- 想定できる未来と理想のギャップは何ですか。その理由は何ですか
- この先の懸念・リスクは何ですか
- この先が楽しみなこと・良い兆しは何ですか
- もし失敗するとしたら、原因は何だと思いますか
- 私たちが目指す場所はどこですか
- 未来の自分・チームへ、何を伝えたいですか
- 前回・前期の目標はどこまで達成できましたか

## 発散(アイデアを出し合う)

新しいアイデアを生み出したり、他のアイデアと組み合わせたりして、ふりかえりの中で使える情報量を増やします。1つのアイデアから、多数のアイデアを生み出すこともできます。

- どんなに小さくくだらないと感じることでも話してみましょう
- 他の人の意見と似ていると思ったものでも、話してみましょう
- 思いついたものを教えてください
- 今考えていることは何ですか
- 別の視点・役割から見ると、どう見えますか

## 収束(アイデアを出し合う)

複数のアイデアを絞り込み、次に議論すべき内容の方針を固めたり、合意をとったりします。発散と収束を使い分けながら、チームにとって良いアクションを作り出しましょう。

- 大事なもの／あまり大事ではないと感じていることは何ですか
- 優先順位の高い／低いものは何ですか
- 効果の高い／低いものは何ですか
- やりたいこと／やりたくないことは何ですか
- それにかかる労力と、得られる効果はどれくらいですか
- それは実行できそうですか。役に立ちそうですか
- その項目のいまの状態は、どれくらい順調ですか
- その意見に、どのくらい近い位置に立ちますか

## アクション(アクションを決める)

学びをアクション（行動）に落とし込みます。SMARTを意識した問いで、今すぐ実行できる小さく具体的なアクションを作りましょう。

- 何をしますか／何をカイゼンしますか
- やってみたいことは何ですか／挑戦したいことは何ですか
- 新しく始めることは何ですか／やめることは何ですか
- 強化したいことは何ですか／弱めたいことは何ですか
- より学びたいことは何ですか／何がチームを成長させますか
- 目標に近づくため／一歩前に進むためにできることは何ですか
- 【Specific】何を・誰が・いつ・どこで・なぜ・どのように行いますか
- 【Measurable】どうしたら実行完了になりますか／効果はどう測りますか
- 【Achievable】そのアクションは実行できますか／難しそうなところは何ですか
- 【Relevant】アクションはどのような効果・影響をもたらしますか
- 【Timely】すぐにできますか／いつまでに行いますか
- 前回のアクションはどうなりましたか（完了／継続中／未着手）
- そのアクションを実行すると、どんなメリットがありますか
- 次に活かせそうなこと／カイゼンできそうなことは何ですか
- 少しだけでも変化を起こすとしたら何ができますか
- 次の目標は何ですか

## ふりかえりをふりかえる(ふりかえりを終える)

ふりかえり自体をふりかえる問いです。ふりかえりの最後に置くことで、進め方や場そのものを少しずつ改善していけます。

- 今日のふりかえり自体の、良かった点は何ですか
- 今日のふりかえり自体で、変えたい点は何ですか
- 次回のふりかえりで試したいことは何ですか
- ふりかえりを終えて、いまの気持ちはどうですか（退出時にひとこと）
