# 進行台本の章立てテンプレート

台本ファイルはこの順序・粒度で作る。特に「削る順番」と「削ってはいけないもの」は初進行者の価値が高いので省かない。

```markdown
# ふりかえり進行台本（日付・チーム名・手法名）

> 終わったら、この行をコピーしてAIに貼ってください: 「ふりかえり終わりました。実施後メモを書きます」

## 0. 事前準備(前日まで)
- ボードの用意(手法に合わせた枠を作っておく。例: YWTならY/W/Tの3列)
- 前回のアクションを手元に

## 1. タイムテーブル
| 時刻 | フェーズ | 分 |
(合計時間から逆算。場づくり1割・思い出す3割・アイデア3割・アクション2割・カイゼン1割が目安)

## 2. 各フェーズの読み上げ文
(冒頭の一言 → 問いかけ → 待ち方 → 切り上げ方、をフェーズごとに。問いは questions.md から選ぶ)

## 3. 時間が押したとき
- 削る順番: (1)共有のコメント往復 (2)アイデアの発散 (3)思い出しの網羅
- 削ってはいけないもの: 場づくりの最初の5分 / アクションを1つ決めること / 最後のふりかえりのふりかえり

## 4. 困ったときの対処
(意見が出ない / 話が偏る / ネガティブに傾く など、tips-fallback.md か search_tips から)

## 5. 実施後メモ(ここに書いて、AIに貼ってください)
- 決まったアクション:
- 時間配分は合っていたか:
- 意見は出たか / 詰まったのはどこか:
- 次に変えたいこと:
```

台本を渡すメッセージには、再開の文言を必ず添える(例: 「実施が終わったら『ふりかえり終わりました』とひとこと貼ってもらえれば、結果のまとめと次回の相談を続きからやります」)。アジェンダビルダーのカレンダー登録(📅)も当日のリマインドとして案内する。
